# 一、函数递归

## 1. 什么是递归？

递归：

> 一个函数调用自己本身。


例如：

```c
void test()
{
    printf("hehe\n");
    test();
}
```

但是这种写法会导致：

- 函数无限调用
- 栈空间不断增加
- 最终导致栈溢出


所以递归必须满足两个条件：

---

## 2. 递归的两个必要条件


### （1）存在限制条件

必须有一个条件让递归停止。


例如：

```c
if(x==0)
{
    return 1;
}
```


---

### （2）每次递归调用都要接近限制条件

否则会出现无限递归。


例如：

正确：

```c
f(x-1);
```


错误：

```c
f(x+1);
```

# 二、递归案例


## 1. 求n的阶乘


数学：

```
n! = n × (n-1)!
```


代码：

```c
int fuc(int x)
{
    if(x==0)
    {
        return 1;
    }

    return fuc(x-1)*x;
}
```


执行过程：

例如：

```
5!

5 × 4 × 3 × 2 × 1
```


---

## 2. 顺序打印一个整数的每一位


例如：

输入：

```
1234
```


输出：

```
1 2 3 4
```


核心：

拆分：

```c
x / 10
```


获取个位：

```c
x % 10
```


代码：

```c
void print(int x)
{
    if(x<10)
    {
        printf("%d",x);
    }
    else
    {
        print(x/10);
        printf("%d",x%10);
    }
}
```


执行过程：

```
1234

print(123)
print(12)
print(1)

输出：

1 2 3 4
```

# 三、递归与迭代


## 1. 递归


特点：

- 函数调用自身
- 使用栈空间保存状态
- 代码更加简洁


缺点：

- 层数过深可能导致栈溢出
- 可能存在重复计算


---

## 2. 迭代


迭代：

> 使用循环解决问题。


例如：

斐波那契数列：

```
1 1 2 3 5 8 13...
```


循环实现：

```c
int fuc(int n)
{
    int a=1;
    int b=1;
    int c=1;

    while(n>=3)
    {
        c=a+b;
        a=b;
        b=c;
        n--;
    }

    return c;
}
```


相比递归：

- 效率更高
- 不占用大量栈空间

---

# 重点总结


正数：

```
原码 = 反码 = 补码
```


负数：

```
原码 ≠ 反码 ≠ 补码
```


例如：

-1


原码：

```
10000000 00000000 00000000 00000001
```


补码：

```
11111111 11111111 11111111 11111111
```


所以：

> int类型中的-1，补码表示为32个1。

# 八、统计一个整数二进制中1的个数


## 方法一：除2取余


代码：

```c
while(num)
{
    if(num%2==1)
    {
        count++;
    }

    num/=2;
}
```


缺点：

只能处理正数。


原因：

负数采用补码存储。


---

# 方法二：移位判断


核心：

```c
(num>>i)&1
```


作用：

判断第i位是否为1。


代码：

```c
for(i=0;i<32;i++)
{
    if(((num>>i)&1)==1)
    {
        count++;
    }
}
```


---

# 方法三：num&(num-1)


代码：

```c
while(num)
{
    num=num&(num-1);

    count++;
}
```


原理：

每执行一次：

消除最低位的1。


优点：

效率更高。
